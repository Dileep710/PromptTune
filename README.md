# PromptTune

PromptTune is an AI-powered prompt engineering platform designed to help users create, optimize, test, and refine prompts for Large Language Models (LLMs). The project aims to improve prompt quality, response accuracy, efficiency, and overall user experience when interacting with AI systems.

## Features

* Create and manage custom AI prompts
* Optimize prompts for better AI responses
* Real-time prompt testing
* User-friendly interface
* Prompt evaluation and refinement
* Lightweight and responsive design
* Built using HTML, CSS, and JavaScript
* Integration with Groq API for AI-powered responses

## Technology Stack

### Frontend

* HTML5
* CSS3
* JavaScript (ES6)

### AI Integration

* Groq API
* Large Language Models (LLMs)

## Getting Started

### Prerequisites

Before using PromptTune, you need a Groq API Key.

1. Create a free Groq account.
2. Generate an API key from your Groq dashboard.
3. Copy your API key for use within the application.

## How to Use

### Step 1: Obtain a Groq API Key

Visit the Groq platform and generate your personal API key.

### Step 2: Launch PromptTune

Open the application in your browser.

### Step 3: Import Your API Key

Paste your Groq API key into the provided API Key field inside the application.

### Step 4: Start Prompt Engineering

* Enter your prompt
* Test different variations
* Evaluate AI-generated responses
* Refine prompts for improved results

## Security Notice

For security reasons, PromptTune does not include any API keys within the source code.

Users must provide their own Groq API key to access AI functionality.

**Important:**

* Never share your API key publicly.
* Do not upload API keys to GitHub repositories.
* Keep your API key private and secure.
* Regenerate your key immediately if it becomes exposed.
